# Sample data

A fictional two-variant corpus for "Jordan Rivera" so you can exercise the
tools without using your own resume. Point the server at this folder:

```bash
resume-mcp --data-dir ./examples/sample-data
```

Then try `list_available_resumes`, `find_resume("Kubernetes")`, and
`retrieve_resume("Jordan_Rivera_Resume_EngManager")`.

Everyone and every company named here is made up.
