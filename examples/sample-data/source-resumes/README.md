# source-resumes/

Drop your `.pdf` and `.docx` resumes here. The server watches this folder and
writes a Markdown copy of each one into `../markdown-resumes/`, then records it
in `../config.json`.

This sample folder is intentionally empty of binaries. The two Markdown files
already in `../markdown-resumes/` are fictional, pre-converted examples so you
can try the tools before adding your own documents.
